1.3 切割原则和切割参数说明

四大切割原则：

  1. 保证语义优先
    例如 md → 按标题切，表格 → 按 sheet 切，ppt → 按页切 ……
  2. 长度可控（真实开发中要动态调整）
    • 考虑嵌入式模型：至多不超过 70%，bge-m3 为 8192 token
    • 考虑重排序模型：bge-reranker-large 为 512
    • 一些规律指标：500 - 1200 token 之间
  3. 边界清晰、有合理的重叠
    • 边界清晰，不能跨域语义
    • 在同一个语义下，二次切块的时候应该有合理的 overlap
  4. 可追溯
    除了切块内容，应该携带关键的筛选数据，例如 title、file_title、item_name、parent_title、part ……

面试题：你的切块是多长？为什么？

答：600。核心原因是根据项目测评系统反复调试，600 时召回率和准确率更高；同时要考虑模型的问题（嵌入式模型、重排序模型的大小），并结合不同文档的切割思路和经验。

1.4 步骤分析

4.4.1 参数获取和校验

  1. 获取三个参数 md_content、file_title、md_path
  2. md_content 非空校验 → 若为空 → 用 md_path 校验并读取
  3. file_title 非空校验 → 若为空 → 用 md_path 校验并取 stem → 取不到则给默认值
  4. 统一换行符号（数据清洗）：md_content 中的 \n\r、\r → 统一为 \n → 写回 state[md_content]
  5. 返回 md_content、file_title
